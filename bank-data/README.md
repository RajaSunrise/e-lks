# Folder Bank Data

Simpan file **Bank Data** hasil unduhan dari halaman Guru ke sini.

Alur:
1. Siswa mengerjakan → klik “Hitung Nilai & Simpan”.
2. Guru klik “Simpan Bank Data” di Halaman Guru.
3. Simpan file itu di sini (boleh ganti nama per kelas, mis. `X-1-2026-10-13`).
4. Untuk membuka rekap lama, guru klik “Buka Bank Data” di Halaman Guru lalu pilih file ini.
